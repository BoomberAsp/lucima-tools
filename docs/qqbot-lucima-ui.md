# Lucima QQ 交互设计

QQ 版沿用桌面端的目录、任务名称、配置顺序和樱粉主题。桌面侧栏映射成 QQ 消息键盘，页面正文映射成消息卡。同一个页面的按钮、斜杠命令和智能体提案共用参数校验、权限和执行逻辑。

## 大厅与导航

发送 `/璐茜玛` 或 `/璐茜玛 大厅` 进入。群聊先 @ 机器人。现有 `/璐西玛`、`/露西玛`、`/lucima` 继续有效。

```text
LucimaTools · 璐茜玛的深层幻影
当前账号 主号 · 授权有效

[ 基本信息 ] [ 自动任务 ] [ 主动任务 ]
[ 佣兵团   ] [ 工具箱   ] [ 运行日志 ]
[ 退出账号 ] [ 切换明暗 ] [ 切换账号 ]
```

| 规则 | QQ 表现 |
| --- | --- |
| 页面标题 | 显示完整名称和路径，例如「主动任务 / 星源商店刷新」。依赖账号的页面同时显示当前账号别名和状态。 |
| 返回与分页 | 子页保留「返回」「大厅」。列表较长时加「上一页」「下一页」，分页保留筛选条件。未登录时仍可进入目录，依赖账号的页面提供登录入口。 |
| 参数输入 | 列表选择后刷新草稿。次数提供常用值和命令输入，多字段配置使用短期网页表单，完成后在 QQ 回显全部参数。 |
| 提交 | 查询可直接执行。写入游戏、消耗资源、开启托管、退出和解绑均经过确认。群内同时显示可复制的确认命令。 |
| 介质 | QQ 官方采用 Markdown 和原生键盘。按钮简称控制在 5 个汉字内，每行最多 3 个，整页最多 5 行和 15 个按钮。OneBot 或卡片不可用时输出同一份页面的文字命令。 |
| 上下文 | 公开目录可由群成员打开。有账号参数、确认编号或个人结果的按钮只接受发起人从原会话使用。 |
| 明暗 | 跟随默认、亮色、暗色作用于机器人生成的菜单图和 PNG 回执。跟随默认使用 Lucima 默认暗色。QQ 原生文字、按钮和聊天背景由客户端绘制。 |

## 九个入口及子目录

| 大厅入口 | 子目录和行为 |
| --- | --- |
| 基本信息 | **账号状态**显示授权方式、等级、快照时间和游戏连接状态。「刷新」拉取快照，「重新扫码」单独提供。**资源**显示体力、旗帜、金币、钻石和招募资源。**团员**和**物品**各有搜索、分页和详情。**队伍**显示名称和站位，供扫荡、活动和深渊选用。群内默认显示摘要，用户可选择在原群展示详细资源。 |
| 自动任务 | **签到与体力**包含每日签到、助战好友、每日体力。**基地生产**包含动力转换、成长药剂、升星水晶、技能模块。**日常循环**包含派遣、秘密商店免费刷新、虚拟幻境、每日免费招募、竞技场 NPC。**活动与奖励**包含每日／周成就、活动投票、兑换码领取。每项详情显示开关、触发条件、选项、最近结果和「执行一次」。 |
| 主动任务 | **日常与商店**包含一键领邮件、商店购买、秘密商店刷新、星源商店刷新、装备活动刷新。**关卡与战斗**包含讨伐扫荡、元素探索、活动关卡、虚构深渊。各项配置、确认和结果见下表。 |
| 佣兵团 | **团概况**显示身份、等级、签到、积分和同步时间。**自动任务**包含自动签到、捐赠、援助、团员商店、团长商店、周奖励。**主动任务**提供团员商店、个人周任务及符合条件的全团积分奖励。捐赠显示资源、单次用量和最低保留量。援助明确材料、对象和次数。团长商店按身份显示可用操作。 |
| 工具箱 | **装备过滤器**提供方案列表、新建、复制、导入、导出、删除、部位及套装／主副属性规则和命中预览。**图鉴查询**支持角色名、属性、职业和卡片。**后台计时测试**显示服务端计划时间、实际开始时间和偏差。桌面端仍在预览中的工具可进入说明页，显示可用能力。 |
| 运行日志 | **当前任务**显示排位、进度、等待选择和取消状态。**任务历史**按账号、任务和结果筛选。**回执**支持文字、PNG 和按编号取回。**清空显示**经确认后隐藏当前账号的展示记录，保留结算与重复提交检查。诊断仅展示允许公开的错误类别和编号。 |
| 退出当前账号 | 先显示当前账号、待处理任务和自动开关，再确认。确认后结束当前授权、取消排队任务、暂停自动执行。运行中的请求等待当前操作结算后停止。随后进入账号列表或登录页。账号别名和配置保留，忘记授权和解绑各有独立入口。 |
| 切换明暗 | 进入主题页选择或一键切换，立即重新出图，保留所在页面。群里只更新发起人的偏好。 |
| 切换账号 | 进入当前会话的账号列表，可切换、重新授权、添加账号或管理别名。切换后保留目录路径，加载该账号的数据、过滤方案、开关和日志。已提交的任务仍锁定提交时的账号。 |

扫码绑定或恢复授权后，QQ 在原会话打开大厅并读取一次账号快照，随后发送 PNG 账号卡。`/lucima 刷新信息` 可重新生成。私聊显示完整信息，群聊先显示基本状态和数量摘要，发起人可确认在原群展开 UID、资源余额和团员预览。快照获取或发送图片失败时，使用文字回执。

### 自动任务的选项

| 任务 | 选项 |
| --- | --- |
| 签到、助战好友、每日体力 | 签到范围、执行时机和下一次可领时间。登录时自动运行助战奖励需纳入已确认的自动规则。 |
| 动力转换、成长药剂、升星水晶、技能模块 | 各有运行条件和最近领取记录，技能模块加速单独授权。 |
| 派遣、免费商店、虚拟幻境 | 派遣可仅领取或确认续派的队伍和体力预算。免费商店可选过滤方案。虚拟幻境显示同步器用量与已通关楼层。 |
| 免费招募、竞技场 NPC | 核对免费额度。竞技场设置目标、每轮旗帜上限和最低保留量。 |
| 成就、活动投票、兑换码 | 选择日／周成就。投票明确对象和额度。兑换码显示候选、历史和最近结果。 |

保存选项与启用自动执行分开。启用时列出账号、触发条件、频率、预算、授权期限和停用方式。已有保存授权仍有效且条件成立才入队。游戏日和冷却以游戏状态为准，计划时刻按北京时间展示。自动任务完成后可在「运行日志」取回结果。

### 主动任务的参数与结果

| 页面 | 配置与结果 |
| --- | --- |
| 一键领邮件 | 预览可领取范围，确认后显示已领取和仍待处理的项目。 |
| 商店购买 | 选商店 → 选商品 → 逐件设置数量 → 确认分币种合计。区分静态参考价与账号货架，执行前再核对成本、余额和限购。 |
| 秘密商店刷新 | 选免费或钻石 → 输入次数 → 可选过滤方案 → 确认。显示每轮货架、匹配装备和已确认消耗。 |
| 星源商店刷新 | 输入次数 → 选装备过滤方案或查看全部 → 确认。命中时展示装备，「结束」「继续剩余次数」「购买」各有明确动作。 |
| 装备活动刷新 | 选套装、部位、主属性、过滤方案、次数和预算。展示当前与候选副属性，采纳时确认。 |
| 讨伐扫荡、元素探索 | `/lucima 讨伐关卡 [属性或关卡ID]` 和 `/lucima 元素关卡 [属性或关卡ID]` 显示账号体力、通关状态及游戏关卡表的体力标价。`/lucima 讨伐扫荡`、`/lucima 元素扫荡` 列出已通关且标价的关卡，点选后补齐队伍、次数（1–99）和体力上限确认。正常扫荡（IsQuickBattle=0），逐轮核对 CostItems 与标价一致，超限或体力不足即停。 |
| 活动关卡 | `/lucima 活动推进` 显示可推进活动、下一关体力标价和队伍 ID。选活动，填写队伍、关数和体力上限后确认。`/lucima 长任务查询 活动扫荡 [活动ID或关卡ID]` 列出当期已通关关卡；`/lucima 活动扫荡 <关卡ID> <队伍ID> <次数> <体力上限>` 发起扫荡确认。仅无额外入场消耗、非服务端战斗、非剧情队伍的关卡可扫荡，每轮重新校验活动仍在当期。 |
| 虚构深渊 | `/lucima 虚构深渊` 显示可挑战与已通关楼层，填写上下半阵容后确认单层挑战，体力上限为 0。独立扫荡余额和结算待核对。 |

虚拟幻境的 `/lucima 幻境扫荡` 会查询最高通关层数和余额。达到既有第 80 层门槛且持有同步器时，点击「准备扫荡」可确认最高层和当前全部同步器。执行前重新核对层数和数量，结算回执显示扣费和奖励。体力消耗为 0。

扫荡体力标价按关卡 ID 读取与部署资源同版本的游戏关卡表。回执显示表版本。只有已通关且价格已知的关卡才显示标价并可选关扫荡，体力余额可用时按快照计算可负担次数。扫荡执行复用桌面端 `sweep_once`/`activity_once` 结算路径，`_finish_scene` 额外返回 `costItems`/`dropItems` 供 QQ 逐轮核对扣费与聚合掉落；任何一轮扣费与标价不符立即停止并保留已确认轮次。

佣兵团积分页提供正常积分进度与符合条件的领奖。桌面端尚无可用执行能力的条目保留可进入的详情页，说明状态和可用操作。

## 两种商店的整数参数

```text
/璐茜玛 刷新秘密商店 [次数] [免费|钻石]
/璐茜玛 刷新星源商店 [次数]
```

- 缺省次数为 1。接受十进制正整数和全角数字，统一归一化。可申请 1–200 次。实际执行上限同时受游戏额度、配置和预算约束。0、负数、小数及多余参数就地提示用法。执行上限低于申请次数时，确认页显示两者和原因。
- 无参数的秘密商店命令保留免费刷新。只传数字且大于 1 时先选「免费／钻石」。免费模式显示可刷 0 或 1 次，剩余次数不等待冷却、不转付费。钻石模式展示可验证的各轮价格和总额上限，再请求确认。
- 星源商店先同步游戏刷新计数、重置状态和可确认的价格，逐轮执行。成本无法核实的付费操作进入「报价不可用」，页面仍可查状态和返回。装备筛选可选「查看全部」。
- 每轮记录实际确认次数和分币种扣款。价格、额度变化或预算不足时停止。结果未知时保留此前已确认的轮次，停止后续轮次。刷新操作的确认不包含任何购买授权。
- 命中方案时归档货架与继续条件、释放进程。继续前再次核对货架、剩余次数和预算，购买另行确认。重启或断线只恢复已知状态，对结算未知的请求停止重发。

## 卡片状态与回执

目录 → 详情 → 参数草稿 → 确认 → 排队 → 执行 → 结果。执行中可进入「等待选择」「请求停止」或「结算待核对」。

- **确认页**显示账号别名、任务、次数、资源上限、提前停止条件和有效期。按钮和 `/璐茜玛 执行 <编号>` 共用同一份一次性确认。修改参数、切换账号或撤销授权使旧确认失效。
- **任务页**提供队列位置、当前阶段、已确认轮数、请求停止和取回回执。维持全站 1 个执行槽、5 个排队位及 12 分钟长任务时限。等待用户选择时释放执行槽，继续时重新入队。
- **结果**区分授权过期、游戏连接失败尚未开始、冷却或额度不足、部分完成、取消和结算未知。登录回执显示授权方式、会话类型、完成时间和编号。任务回执显示项目、请求和实际完成次数、已确认扣款及结果。
- **PNG**与文字使用同一份已确认数据。图片采用 Lucima 的主题令牌和卡片布局。主动操作结果在发起会话可见，QQ 回复窗口失效时通过 `/璐茜玛 回执 <编号>` 取回。

## 账号、权限与数据

- 会话继续按平台、机器人、会话类型、群和发起人隔离。新增每个会话的账号列表与当前账号指针。已有单账号绑定迁移为首个账号，保留归属、授权期限和加密存储。一个游戏账号继续只绑定一个 QQ 会话，跨会话迁移仍从原会话解绑。
- 草稿、确认、已入队任务、自动规则、过滤方案和回执都记录账号标识。切换当前账号只影响之后打开的页面和新操作。群内使用自定义别名或「账号 A」。
- 账号密码只在登录网页输入。模板、PNG 和日志只取允许展示的字段。多字段网页草稿使用与发起人和会话绑定的短期链接。
- 按钮只发送短操作引用，后端按动作表解析固定动作和参数。命令与智能体走同一动作表，每项定义输入、权限、确认、预算、成功条件和错误回执。

## 实现与验收

| 阶段 | 验收条件 |
| --- | --- |
| 导航与渲染 | 九个大厅入口、两种主题、群聊和私聊按钮、OneBot 命令降级均可进入同一页面。完成返回、分页和回执取回。 |
| 商店与运行状态 | 覆盖次数无效、冷却、价格变化、切号、跨群确认、扣款后断线、取消及 QQ 图片拒绝。 |
| 多账号与任务接入 | 校验旧绑定迁移、切换、注销、撤销凭证和各账号独立的托管、日志和偏好。逐项以真实游戏支持和明确结算验证任务执行。 |
| 上线 | 先用模拟结果覆盖所有状态，再使用受控账号测试群聊登录、确认、两种商店、回执及适配器行为。 |
